# russvaccaro.com

Russell Vaccaro's personal site, built with [Jekyll](https://jekyllrb.com/) and
the Minima theme and hosted by GitHub Pages.

## Local development

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open <http://localhost:4000>.

Pages live at the repository root. Add published articles to `_posts` using
Jekyll's `YYYY-MM-DD-title.md` filename convention. Site-wide navigation and
metadata are configured in `_config.yml`.
